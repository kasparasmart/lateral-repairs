# Certificate PDF

The certification **logos** in the `#certifications` section are non-clickable
trust badges (their images live in `images/certs/`).

Below them, one **clickable document** links to the official certificate PDF:

| Link on site | File |
| --- | --- |
| ISO 9001:2015 certificate → "View PDF" | `iso-certificate.pdf` |

`iso-certificate.pdf` is currently a **branded placeholder** so the link works.
Replace it with the official ISO 9001:2015 certificate issued by Sistemų Registras
(keep the same filename) to publish the real document — no code changes needed.

To add more downloadable certificates later, drop the PDF here and add a matching
`.cert-doc` block in `index.html`.
