# Certificate PDFs

The certification logos in the `#certifications` section each link to a PDF that
opens in a new tab. Drop the corresponding certificate documents here using these
exact filenames so the links resolve:

| Link on site | Expected file |
| --- | --- |
| ISO 9001 · 14001 · 45001 | `iso.pdf` |
| SINTEF (TG 20926) | `sintef.pdf` |
| Eurofins | `eurofins.pdf` |
| NSF | `nsf.pdf` |
| WRc | `wrc.pdf` |

The logos themselves live in `images/certs/` and are already wired up. Until a PDF
is added here, clicking that logo will 404 — add the file (or ask to have the link
point elsewhere) to complete it.
